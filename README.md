# Carbon Footprint Management System (Module 3)

## Prerequisites

- [.NET 9 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/9.0)
- A code editor or IDE (e.g., Visual Studio 2022+, Visual Studio Code)

## 🚀 How to Run the Project
The project uses C# and runs on .NET 9.0 SDK.

### 🔧 Cloning the Repository

To clone only the `module3-merge-final` branch:
```
git clone --branch module3-merge-final --single-branch https://github.com/ICT2112SoftwareDesign/ICT2112-Software-Design-ClassP1.git 
```

### 📦 Restoring Dependencies
1. Open a terminal in your IDE or project folder.
2. Restore NuGet packages by running:

```
dotnet restore
```
### ▶️ Running the Project
Build and run the project using:
```
dotnet build
dotnet run
```
